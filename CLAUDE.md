# MetalCut

Веб-приложение для гильотинного раскроя листового металла. Один файл
`index.html`, без сборки и зависимостей — открывается прямо в браузере.

Учёт сервисов и аккаунтов (GitHub/Cloudflare/OpenAI) — см. [ПАМЯТКА.md](ПАМЯТКА.md).
Там же — что делать, если что-то сломалось.

## Структура

- `index.html` — весь фронтенд: форма ввода, алгоритм упаковки деталей на
  лист (гильотинные резы), отрисовка SVG-карты раскроя, история в
  localStorage, распознавание фото через воркер.
- `build.sh` — собирает `docs/index.html` из `index.html` (добавляет
  манифест, иконки, регистрацию service worker). Запускать после каждой
  правки `index.html`.
- `docs/` — то, что реально отдаёт GitHub Pages. Не редактировать руками —
  перезаписывается сборкой.
- `worker/index.js` — Cloudflare Worker: прокси к OpenAI Vision, прячет
  ключ, проверяет Origin, считает суточный лимит через KV.
- `worker/wrangler.toml` — конфиг воркера (KV binding и т.п.).

## Деплой

```bash
bash build.sh && git add -A && git commit -m "..." && git push   # сайт
cd worker && wrangler deploy                                      # воркер
```

Сайт: https://amuravschi-cloud.github.io/Metalcut/
Воркер: https://metalcut-vision.amuravschi-cloud.workers.dev

## Уже сделано (не переизобретать)

- Упаковка: гильотинное дерево резов, перебор вариантов (положение деталей
  по типам, режим размещения «в угол»/«по отходу», 4 сортировки, 5 правил
  деления). Выбор лучшего: 1) меньше листов, 2) **больше самый крупный
  цельный кусок** (для гильотины — свободный лист дерева, для плазмы —
  наибольший пустой прямоугольник), 3) шире кусок, 4) аккуратные остатки
  (кратно 500 мм), 5) меньше остатков и резов. Оптимизатор сам перебирает
  положения деталей; кнопка «Повернуть все детали» — ручная страховка:
  разворачивает все детали на 90° относительно авто-раскладки (состояние
  `FORCE`, `inp.forceOrient`) и заново собирает компактную раскладку; повторное
  нажатие («Вернуть авто-раскладку») возвращает подбор программы. Обычный
  пересчёт тоже возвращает авто-режим.
- Карта раскроя — SVG, подписи с адаптивным кеглем (не мельче порога
  читаемости), масштаб на телефоне через кнопки −/+/«По ширине».
- Кнопка «Новый раскрой» — очищает заказ и детали, оставляет размер листа
  и параметры реза.
- Распознавание фото рукописного эскиза/списка через OpenAI (`gpt-4o`) —
  идёт через Cloudflare Worker, ключ на клиент не попадает. После
  распознавания показывается **превью с подтверждением** (кнопки «Верно» /
  «Отмена») — форма не перезаписывается молча.
- Суточный лимит на распознавание — 60/сутки, KV-счётчик на воркере.
- PWA: иконка, манифест, офлайн-кэш, добавление на экран «Домой».
- Печать (карта + таблицы резов/деталей на отдельный лист на каждый лист
  металла).
