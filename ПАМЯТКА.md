## GitHub

**Зачем заводил:** хостинг для публичной ссылки на сайт (GitHub Pages) — чтобы приложение открывалось у любого человека без входа куда-либо.

- Аккаунт: `amuravschi-cloud`
- Репозиторий: https://github.com/amuravschi-cloud/Metalcut
- Публичный сайт (сюда даёте ссылку клиентам/мастерам): **https://amuravschi-cloud.github.io/Metalcut/**
- Где включена публикация: Settings → Pages → Source: `main` / `docs`
- Что там лежит: только код приложения. Никаких ключей и паролей.

**Как обновить сайт после правки кода:**
```bash
cd ~/Documents/MetalCut
bash build.sh
git add -A && git commit -m "правка" && git push
```
Через 1–2 минуты изменения появляются на сайте сами.

## Cloudflare

**Зачем заводил:** нужен был сервер-посредник, чтобы спрятать ключ OpenAI. На GitHub Pages ничего спрятать нельзя — любой код виден в браузере, поэтому сам вызов OpenAI перенесён на маленький серверный скрипт (Worker), а ключ лежит только там.

- Аккаунт: `A.muravschi@gmail.com`
- Панель: https://dash.cloudflare.com
- Что создано в этом аккаунте:
  - **Worker** (серверный скрипт) — `metalcut-vision`, адрес `https://metalcut-vision.amuravschi-cloud.workers.dev`. Найти: Workers & Pages → metalcut-vision.
  - **Secret** (спрятанный ключ) — `OPENAI_API_KEY`, привязан к этому воркеру. Посмотреть/сменить: Workers & Pages → metalcut-vision → Settings → Variables and Secrets. Значение никогда не показывается — можно только перезаписать.
  - **KV-хранилище** (счётчик) — `METALCUT_LIMIT`, считает, сколько фото распознано за сутки, чтобы ограничить лимит 60 в сутки и не спалить весь баланс OpenAI при утечке.
- Тариф: бесплатный (Free), карта не требуется.

**Как обновить воркер после правки `worker/index.js`:**
```bash
cd ~/Documents/MetalCut/worker
wrangler deploy
```

## OpenAI

**Зачем заводил / для чего используется:** платный ключ (ChatGPT API), на нём уже был баланс. Используется только для одной функции — распознавание фото рукописного эскиза раскроя (кнопка «📷 Сфотографировать чертёж»), модель `gpt-4o`.

- Баланс и расход: https://platform.openai.com/usage
- Сам ключ: **нигде не хранится у вас** — только внутри Cloudflare (см. выше). Если нужно посмотреть/поменять ключ — заходите в OpenAI, создаёте новый, вписываете его в Cloudflare командой:
  ```bash
  cd ~/Documents/MetalCut/worker
  wrangler secret put OPENAI_API_KEY
  ```
- Лимит расхода со своей стороны: 60 распознаваний в сутки (защита на стороне Cloudflare, см. выше).

## Если что-то пошло не так

| Проблема | Что делать |
|---|---|
| Сайт не открывается | Проверить https://github.com/amuravschi-cloud/Metalcut → вкладка Actions — не упала ли сборка |
| Распознавание фото не работает | Cloudflare → metalcut-vision → Logs, посмотреть ошибку. Частая причина — кончился баланс на OpenAI |
| Подозреваете утечку ключа OpenAI | Смените ключ на platform.openai.com, впишите новый через `wrangler secret put OPENAI_API_KEY` |
| Нужно временно отключить распознавание фото | В Cloudflare удалить/переименовать Secret `OPENAI_API_KEY` — функция начнёт вежливо отказывать, сайт при этом продолжит работать |
