# MetalCut — раскрой листового металла

Веб-приложение для гильотинного раскроя листового металла. Работает в браузере,
без сервера и без интернета: расчёт, карта раскроя, порядок резов и история —
всё на устройстве.

## Что умеет

- Раскладка деталей по листам с учётом **толщины реза гильотины** и **обрезки кромки**.
- Все резы сквозные — раскрой физически выполним на гильотине.
- **Порядок резов**: номер, направление, отметка от упора и длина каждого реза.
- Карта раскроя с цветами по типам деталей, размерами, номерами и площадью.
- Деловой остаток выделяется отдельно.
- Поворот деталей на 90° (можно запретить — например, для металла с направлением проката).
- История раскроев в браузере, печать и сохранение в PDF.
- Адаптив: десктоп и телефон, установка на экран «Домой».

## Структура

| Файл | Назначение |
|---|---|
| `index.html` | исходник приложения — единственный файл, который нужно править |
| `build.sh` | пересобирает версию для хостинга из `index.html` |
| `docs/` | то, что публикуется на GitHub Pages |
| `docs/sw.js` | офлайн-кэш (service worker) |
| `docs/manifest.webmanifest`, `docs/icon-*.png` | установка как приложения |

## Разработка

Откройте `index.html` в браузере — этого достаточно, сборка не нужна.

После правок пересоберите публикуемую версию:

```bash
bash build.sh
```

При изменении файлов поднимите `VERSION` в `docs/sw.js`, иначе у тех, кто уже
открывал сайт, останется старая версия из кэша.

## Публикация

GitHub Pages: Settings → Pages → Source: `main`, папка `/docs`.
